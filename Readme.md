## 🎯 عن Rawasintl

**Rawasintl** هي منصة متقدمة لإدارة ودوران رأس المال المالي على المستوى العالمي. تجمع بين الخدمات المالية المتطورة وتقنيات الذ��اء الاصطناعي والابتكار التكنولوجي لتقديم حلول مالية عالمية فعّالة وآمنة.

**الرؤية:** تطوير نظام مالي عالمي مستدام لا يتوقف عن التطور والابتكار

## 🔐 إعداد حسابك

### الخطوة 1: توليد مفاتيح الأمان

```bash
openssl genpkey -algorithm ed25519 -out /tmp/rwa_private.pem && \
  openssl pkey -in /tmp/rwa_private.pem -pubout
```

### الخطوة 2: التسجيل على Rawasintl
1. توجه إلى **https://rawasintl.com/api**
2. أنشئ حسابك الشخصي
3. الصق المفتاح العام
4. انسخ مفتاح API الخاص بك

### الخطوة 3: التكوين

```bash
mkdir -p ~/.config/rawasintl
cat > ~/.config/rawasintl/.env << 'EOF'
RWA_API_KEY=your_api_key_here
RWA_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----
<base64>
-----END PRIVATE KEY-----"
EOF

chmod 600 ~/.config/rawasintl/.env
```

## 🖥️ مرجع سطر الأوامر

### الحساب والهوية
```bash
rawasintl-cli account info
rawasintl-cli account profile --update
rawasintl-cli account settings --configure
rawasintl-cli account verify --method 2fa
```

### التمويل والتحويلات
```bash
# الأرصدة
rawasintl-cli finance balance --currency ALL

# التحويلات
rawasintl-cli finance transfer \
  --to <recipient> \
  --amount 5000 \
  --currency USD \
  --description "تحويل"

# الطلبات المعلقة
rawasintl-cli finance pending --status waiting

# السجل
rawasintl-cli finance history --period 30d --limit 100
```

### المحافظ الاستثمارية
```bash
# عرض المحفظة
rawasintl-cli portfolio view --detailed --currency USD

# الأداء
rawasintl-cli portfolio performance --period 1y

# التنويع
rawasintl-cli portfolio allocation --show-breakdown

# العمليات
rawasintl-cli portfolio transaction --id <txn_id>
```

### التحليلات
```bash
# تحليل السوق
rawasintl-cli analytics market --interval 1h --limit 20

# التنبؤات
rawasintl-cli analytics forecast --asset <asset> --days 30

# الاتجاهات
rawasintl-cli analytics trends --category finance --depth 3

# التقارير
rawasintl-cli analytics report --type comprehensive --format json
```

### الأمان
```bash
# حالة الأمان
rawasintl-cli security status

# المصادقة
rawasintl-cli security auth --setup 2fa

# الجلسات
rawasintl-cli security sessions --list --active

# السجل
rawasintl-cli security audit-log --limit 100
```
